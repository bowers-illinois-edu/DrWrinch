# Package index

## Bayes factors

Compute Bayes factors under the binomial and hypergeometric urn models.

- [`bf_binomial()`](https://bowers-illinois-edu.github.io/DrWrinch/reference/bf_binomial.md)
  : Bayes factor under the binomial model
- [`bf_urn()`](https://bowers-illinois-edu.github.io/DrWrinch/reference/bf_urn.md)
  : Bayes factor under the hypergeometric urn model

## Sensitivity analysis

Locate the smallest perturbations of observation bias and prior that
flip the conclusion.

- [`sens_binomial()`](https://bowers-illinois-edu.github.io/DrWrinch/reference/sens_binomial.md)
  : Sensitivity analysis for the binomial Bayes factor
- [`sens_urn()`](https://bowers-illinois-edu.github.io/DrWrinch/reference/sens_urn.md)
  : Sensitivity analysis for the urn Bayes factor
